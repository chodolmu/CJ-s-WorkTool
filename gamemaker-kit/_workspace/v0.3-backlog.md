# gamemaker-kit v0.3 Backlog — Skeleton Completion

**Date**: 2026-05-14
**Source**: `_workspace/v0.3-skeleton-audit.md` — 7-axis structural audit. Not dogfood-driven.
**Scope**: v0.2 뼈대의 *형태로는 약속됐지만 작동으로는 없는* 항목을 완성. 신규 SKILL 추가 0, 신규 agent 추가 0.

---

## 0. v0.3의 한 줄 약속

> "**v0.2 뼈대를 *작동 가능*하게 만든다. v0.2가 약속한 4축·6직군·4 specialists·dev-complete endpoint가 *형태로만* 존재하는 부분을 *연결*한다.**"

- v0.3 = 연결(wiring) + 문서 정합성. 기능 추가 아님.
- 신규 SKILL/agent 0개. 기존 SKILL의 *호출 경로 추가* + structure.md 갱신 + 새 작은 SKILL 1-2개 (endpoint용)로 모두 해결.
- dogfood findings 11개는 **v0.4 backlog**로 보존 (v0.3 scope 밖).
